==================================================
1. worker/hardware.py
==================================================

Create a hardware detection module.

Implement a clean function such as:

get_hardware_info()

It should return structured information containing:

- cpu_count
- ram_total
- gpu
- gpu_memory
- cuda_available
- torch_version
- python_version
- platform

CPU:
Use psutil.cpu_count(logical=True).

RAM:
Use psutil.virtual_memory().
Store total RAM in bytes or another clearly documented unit.

GPU:
Use PyTorch when available.

If CUDA is available:

- torch.cuda.is_available()
- torch.cuda.get_device_name(0)
- torch.cuda.get_device_properties(0).total_memory

Detect the first CUDA GPU for now.

If CUDA is unavailable:

gpu = "None"
gpu_memory = 0
cuda_available = False

The module MUST NOT crash when:
- PyTorch is unavailable
- CUDA is unavailable
- NVIDIA GPU does not exist

Use graceful fallback behavior.

Do not assume that every worker has a GPU.

==================================================
2. WORKER ID
==================================================

Implement worker ID handling.

Allow an explicit worker ID through an environment variable:

COLABCLUSTER_WORKER_ID

Example:

COLABCLUSTER_WORKER_ID=COLAB-01

If the environment variable is not present, generate a unique worker ID using UUID.

Example:

worker-a13f8c2d

Create a helper function:

get_worker_id()

The generated ID should remain stable for the lifetime of the worker process.

==================================================
3. worker/worker.py
==================================================

Create a minimal Worker class.

Example conceptual interface:

class Worker:
    def __init__(self, worker_id=None):
        ...

    def get_hardware_info(self):
        ...

    def get_info(self):
        ...

The Worker should contain:

- worker_id
- hardware information

Do NOT connect it to the controller yet.

Add a simple CLI entry point.

Running:

python -m worker.worker

should print readable worker information.

Example:

========================================
        COLABCLUSTER WORKER
========================================

Worker ID      : COLAB-01
CPU Cores      : 4
RAM            : 12.7 GB
GPU            : Tesla T4
GPU Memory     : 15.0 GB
CUDA Available : True
PyTorch        : 2.x.x
Python         : 3.x.x
Platform       : Linux

========================================

The exact values must come from the actual machine.

If running without a GPU:

GPU            : None
GPU Memory     : 0 GB
CUDA Available : False
